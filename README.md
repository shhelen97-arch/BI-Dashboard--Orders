# תמונת מצב הזמנות · Orders Snapshot

דשבורד ניהולי בעברית לקובץ ההזמנות החודשי של מרכז לוגיסטי (ייצוא "Shipped Orders" מה-WMS).
גוררים קובץ Excel או CSV ומקבלים מיד מדדי מפתח, גרפים, תובנות אוטומטיות וטבלת חריגות.

**אתר חי:** https://orders-snapshot.vercel.app

## מה הכלי עושה
- זיהוי אוטומטי של העמודות (שמות באנגלית או בעברית, ואם לא נמצא, ניחוש לפי התוכן), ומסך בחירה ידנית כשחסרה עמודה חיונית
- בחירת חודש; ברירת המחדל היא החודש המלא האחרון, וחודש חלקי מסומן באזהרה
- 6 מדדי מפתח, 4 גרפים (מובילים, סוג משלוח, 5 הלקוחות המובילים, נפח יומי) ו-3 עד 5 תובנות בעברית
- טבלת חריגות של הזמנות שלא נמסרו, לפי סטטוס ומוביל

## פרטיות
הקובץ מעובד בדפדפן בלבד ואינו נשלח לשום שרת. עמודת שמות הנמענים (Ship To) לא מוצגת בשום מקום.
קובצי נתוני אמת אינם נשמרים בריפו (ראו `.gitignore`); בתיקייה `test-data` יש נתונים מומצאים בלבד.

## הרצה
אין צורך בהתקנה: פותחים את `index.html` בדפדפן (נדרש חיבור לאינטרנט לטעינת הספריות).
בדיקות: פותחים את `tests/tests.html`.

## טכנולוגיות
HTML, CSS ו-JavaScript נקי · SheetJS · Chart.js · פורסם ב-Vercel · פותח עם Claude Code
